BACKGROUND & EXPERIENCE

Learning by making.

My studies in ISM 6225 have helped me build a foundation in research, communication and digital problem-solving. This project is an opportunity to turn those skills into a useful, accessible resource.

I began by planning the audience, page structure and shared visual identity. I then constructed each page with semantic HTML and responsive CSS, adding JavaScript for the gallery manager, local data storage and interactive analytics. GitHub Copilot helped me draft and refine code; I reviewed the output and tested the interactions. The finished static files are designed for deployment through GitHub Pages.
